# 커넥터와 도구 확인법

스킬은 도구 이름을 하드코딩하지 않고 기능으로 부른다. 환경마다 도구 이름 접두어가 다르기 때문이다. 작업을 시작하기 전에 필요한 커넥터가 연결되어 있는지 확인한다.

| 대상 | 필요도 | 없을 때 |
|---|---|---|
| 노션 커넥터 | 필수 | 멈춘다 |
| Gmail 커넥터 | 선택 (메일 알림) | 진행한다. 알림은 세션 안에서만 보고한다 |
| Playwright 서버 | 선택 (지원서 자동입력, 일부 공고 열람) | 진행한다. apply 와 웹 공고 확인이 안 된다 |

## 노션 커넥터

claude.ai 커넥터이므로 플러그인이 설치해 줄 수 없다.

1. 사용 가능한 도구 중 노션의 검색, 조회, 페이지 생성, 페이지 갱신, DB 생성, 뷰 생성 도구가 보이는지 본다
2. 안 보이면 ToolSearch 로 `notion` 을 검색해 도구 스키마를 불러온다
3. 그래도 없으면 사용자에게 안내하고 멈춘다: "claude.ai 설정 > 커넥터에서 Notion 을 켜고 연결한 뒤 새 세션에서 다시 실행해 주세요"
4. 연결은 되어 있는데 페이지를 못 찾으면, 노션 쪽에서 연결 계정이 해당 페이지에 접근 권한이 있는지 확인하도록 안내한다

## Gmail 커넥터

마감 알림 메일에만 쓴다.

1. 사용 가능한 도구 중 Gmail 의 초안 작성이나 발송 도구가 보이는지 본다
2. 안 보이면 ToolSearch 로 `gmail` 을 검색한다
3. 그래도 없으면 멈추지 말고 알린다: "Gmail 커넥터가 없어 메일 알림은 못 보냅니다. 알림은 이 세션에서만 알려 드립니다. 메일로 받으려면 claude.ai 설정 > 커넥터에서 Gmail 을 켜 주세요"
4. 알림 수신 주소는 플러그인 설정 `notify_email` 이다. 비어 있으면 메일을 보내지 않는다

## Playwright 서버

플러그인이 `.mcp.json` 으로 Playwright MCP 서버를 묶어 두었다. 플러그인 서버는 보통 `plugin:jobflow:playwright` 라는 이름으로 나타난다.

1. 사용 가능한 도구 중 브라우저 이동, 스냅샷, 클릭, 입력 도구가 보이는지 본다
2. 안 보이면 ToolSearch 로 `playwright` 또는 `browser` 를 검색한다
3. 사용자가 따로 쓰는 Playwright 서버(이름이 달라도 같은 기능)가 이미 연결되어 있으면 그것을 써도 된다
4. 도구가 없거나 서버가 뜨지 않으면 Node.js 설치(`node -v`, `npx -v`)를 확인하게 하고, `/mcp` 로 서버 상태를 보게 한다
5. 도구는 있는데 브라우저가 없다는 오류가 나면 Playwright 브라우저 설치(`npx playwright install chromium`)를 안내한다. 설치는 사용자 승인을 받고 진행한다

## 확장 모드 (선택 사항)

기본 Playwright 는 별도의 새 브라우저를 띄운다. 이미 로그인해 둔 내 크롬 탭에 붙어서 작업하고 싶다면 Playwright MCP 의 확장 모드(`--extension`)와 브라우저 확장 프로그램을 따로 설정할 수 있다. 필수가 아니며, 설정하지 않아도 모든 기능을 쓸 수 있다. 확장 모드에서는 파일 첨부가 막히는 경우가 있어 첨부는 사람이 직접 해야 할 수 있다. 다른 세션이 연결을 가져가면 탭이 초기화될 수 있으니 한 번에 한 세션만 쓴다.
